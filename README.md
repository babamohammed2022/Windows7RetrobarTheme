# Windows 7 RetroBar Theme

This is a custom visual skin for RetroBar that replicates the Windows 7 taskbar interface, featuring a recreated system tray overflow menu, native-style icon hover state animations, and an animated Start button fade-in effect. This theme has been tested and verified on Windows 10 versions 21H2 and 22H2.

## Features

* Recreated system tray overflow menu
* Windows 7-style hover state animations for system tray icons
* Fade-in transition effect for the Start button

## Installation Guide

To install this theme, [RetroBar](https://github.com/dremin/RetroBar) must be present on the system. Navigate to `%LOCALAPPDATA%\RetroBar` and extract the contents of the archive file (or manually copy the `Resources` and `Themes` folders into the directory mentioned above). Once completed, open RetroBar settings and select the Windows 7 theme.

## Technical Limitations

* **Superbar Implementation:** This feature is conceptually recreated in design, but it is not fully functional as it requires custom modifications within the core RetroBar source code.
* **Transparency:** The Aero Glass transparency is a best-effort visual recreation based on the rendering capabilities of RetroBar.
